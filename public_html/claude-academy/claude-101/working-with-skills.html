What are Skills?

Skills là gì?
Plan availability: Skills are currently a feature preview for Pro, Max, Team, and Enterprise plans. If you're on the Free plan, you can read along to understand the concept and skip the hands-on steps.

Skills are folders of instructions, scripts, and resources that Claude loads dynamically to improve performance on specialized tasks. Think of them as expertise packages — they teach Claude how to complete specific tasks in a repeatable way.

You've already seen Skills at work if you've used Claude to create Excel spreadsheets, PowerPoint presentations, Word documents, or PDFs. Those file creation capabilities are powered by Skills running behind the scenes. But Skills go far beyond document creation. Custom Skills can codify entire repeatable workflows — a quarterly variance analysis methodology, a brand voice review process, or a compliance checklist — so Claude follows the same rigorous steps every time.

Gói plan: Skills hiện là tính năng preview cho các gói Pro, Max, Team và Enterprise. Nếu bạn dùng gói Free, bạn có thể đọc để hiểu khái niệm và bỏ qua các bước thực hành.

Skills là các thư mục hướng dẫn, script và tài nguyên mà Claude tải động để cải thiện hiệu suất trên các nhiệm vụ chuyên biệt. Hãy nghĩ chúng như các gói chuyên môn — chúng dạy Claude cách hoàn thành các nhiệm vụ cụ thể theo cách có thể lặp lại.

Bạn đã thấy Skills hoạt động nếu đã dùng Claude để tạo bảng tính Excel, bản trình bày PowerPoint, tài liệu Word hoặc PDF. Các khả năng tạo file đó được vận hành bởi Skills chạy ngầm. Nhưng Skills vượt xa việc tạo tài liệu. Custom Skills có thể mã hóa toàn bộ quy trình lặp lại — phương pháp phân tích variance hàng quý, quy trình đánh giá giọng nói thương hiệu, hoặc checklist tuân thủ — để Claude luôn thực hiện các bước nghiêm ngặt giống nhau.

Types of Skills

Các loại Skills

There are two categories of Skills you'll encounter:

  • Anthropic Skills are created and maintained by Anthropic. These include enhanced document creation capabilities for Excel, Word, PowerPoint, and PDF files. Anthropic Skills are available to all paid users and Claude invokes them automatically when relevant — you don't need to do anything special to use them.
  • Custom Skills are ones you or your organization create for specialized workflows and domain-specific tasks. For example, you might create a skill that applies your company's brand guidelines to presentations, structures meeting notes in a specific format, or executes your organization's data analysis workflows.

Có hai loại Skills bạn sẽ gặp:

  • Anthropic Skills được tạo và duy trì bởi Anthropic. Chúng bao gồm các khả năng tạo tài liệu nâng cao cho Excel, Word, PowerPoint và PDF. Anthropic Skills có sẵn cho tất cả người dùng trả phí và Claude tự động kích hoạt chúng khi phù hợp — bạn không cần làm gì đặc biệt để sử dụng.
  • Custom Skills là những skills bạn hoặc tổ chức của bạn tạo ra cho các quy trình chuyên biệt và nhiệm vụ theo lĩnh vực cụ thể. Ví dụ, bạn có thể tạo skill áp dụng brand guidelines của công ty vào bài thuyết trình, cấu trúc ghi chú cuộc họp theo định dạng cụ thể, hoặc thực hiện quy trình phân tích dữ liệu của tổ chức.

Enabling Skills

Bật Skills

Skills are currently available as a feature preview for users on Pro, Max, Team, and Enterprise plans. To use Skills, you'll need to have Code execution and file creation enabled, since Skills require Claude's secure sandboxed computing environment to function.

Here's how to enable Skills:

  1. Navigate to Settings > Capabilities
  2. Ensure that Code execution and file creation is toggled on
  3. Scroll to the Skills section
  4. Toggle individual skills on or off as needed

For Enterprise plans, organization Owners must first enable both Code execution and Skills in Admin settings before individual members can access them.

For Team plans, this feature preview is enabled by default at the organization level.

Skills hiện có sẵn dưới dạng tính năng preview cho người dùng gói Pro, Max, Team và Enterprise. Để dùng Skills, bạn cần bật Code execution và file creation, vì Skills yêu cầu môi trường điện toán sandbox bảo mật của Claude để hoạt động.

Cách bật Skills:

  1. Điều hướng đến Settings > Capabilities
  2. Đảm bảo Code execution and file creation đã bật
  3. Kéo xuống phần Skills
  4. Bật hoặc tắt từng skill theo nhu cầu

Với gói Enterprise, Owners của tổ chức phải bật cả Code execution và Skills trong Admin settings trước khi các thành viên có thể truy cập.

Với gói Team, tính năng preview này được bật mặc định ở cấp độ tổ chức.

Using Skills in practice

Dùng Skills trong thực tế

The beauty of Skills is that you typically don't need to think about them — Claude handles skill selection automatically based on your request. Here are some examples of prompts that would invoke Skills:

  • "Create an Excel spreadsheet tracking monthly expenses with formulas for totals"
  • "Turn this meeting notes document into a PowerPoint presentation"
  • "Generate a PDF report summarizing this data"
  • "Build a financial model in Excel with scenario analysis"

When Claude uses a Skill, you'll see it mentioned in Claude's chain of thought as it works. The output will be a downloadable file you can save to your computer or directly to Google Drive.

Điều tuyệt vời của Skills là bạn thường không cần nghĩ đến chúng — Claude tự động chọn skill dựa trên yêu cầu của bạn. Đây là một số ví dụ prompt sẽ kích hoạt Skills:

  • "Tạo bảng tính Excel theo dõi chi phí hàng tháng với công thức tính tổng"
  • "Chuyển tài liệu ghi chú cuộc họp này thành bài thuyết trình PowerPoint"
  • "Tạo báo cáo PDF tóm tắt dữ liệu này"
  • "Xây dựng mô hình tài chính trong Excel với phân tích kịch bản"

Khi Claude dùng Skill, bạn sẽ thấy nó được đề cập trong chuỗi suy nghĩ của Claude khi làm việc. Đầu ra sẽ là file có thể tải xuống, bạn có thể lưu về máy tính hoặc trực tiếp vào Google Drive.

File execution

Thực thi file

Claude works with you on slides, spreadsheets, and contract redlines. This capability means Claude can work with your actual files (within a contained environment) to create updated versions. Upload slides, spreadsheets, contracts, or any .xlsx, .pptx, .docx, or .pdf files — and watch as Claude creates slides, performs analyses, and adds suggested edits. When done, you can download these files or open them in Drive.

Security considerations

Lưu ý bảo mật

Because Skills can include executable code, it's important to use them thoughtfully:

  • Only install custom Skills from trusted sources
  • Anthropic's built-in Skills are tested and maintained by Anthropic
  • Custom Skills you upload are private to your individual account
  • If you're installing a custom Skill from an external source, review its contents before use to understand what it does

Vì Skills có thể bao gồm code có thể thực thi, điều quan trọng là sử dụng chúng một cách cẩn thận:

  • Chỉ cài đặt Custom Skills từ nguồn đáng tin cậy
  • Anthropic Skills tích hợp được Anthropic kiểm tra và duy trì
  • Custom Skills bạn upload là riêng tư với tài khoản cá nhân của bạn
  • Nếu cài đặt Custom Skill từ nguồn bên ngoài, hãy xem lại nội dung trước khi dùng để hiểu nó làm gì

Creating custom skills

Tạo custom skills

While Anthropic's built-in Skills cover common document creation tasks, the real power of Skills comes from creating your own. Custom Skills let you teach Claude your specific workflows, brand guidelines, and ways of working — so Claude can apply that knowledge automatically whenever it's relevant.

The easiest way to create a custom Skill is through conversation with Claude itself. You don't need to write code or manually create files — Claude handles the technical structure for you.

Here's how to create a Skill through conversation:

  1. Start a new chat and tell Claude what you want to create. For example: "I want to create a skill for writing quarterly business reviews" or "I need a skill that applies our brand guidelines to presentations."
  2. Answer Claude's questions. Claude will interview you about your workflow, asking things like: What should this skill do? What makes good output for this type of work? Can you give examples of when you'd use this skill?
  3. Upload reference materials if you have them. Templates, style guides, brand assets, or examples of work you're proud of all help Claude understand exactly what you're looking for.
  4. Save your skill. When finished, Claude generates a file containing your properly structured skill. Save it and the skill will be ready for Claude to use.

See your skills: Find the Customize tab in the left sidebar. There you can see all available skills and even edit them manually or by chatting with Claude.

Your custom Skill will appear in your Skills list alongside Anthropic's built-in Skills. From that point forward, Claude will automatically invoke it whenever you work on relevant tasks. You can improve your skills with iteration — ask Claude to edit a skill and it will update the files for you.

Trong khi Anthropic Skills tích hợp bao gồm các nhiệm vụ tạo tài liệu phổ biến, sức mạnh thực sự của Skills đến từ việc tạo của riêng bạn. Custom Skills cho phép bạn dạy Claude các quy trình cụ thể, brand guidelines và cách làm việc của bạn — để Claude có thể tự động áp dụng kiến thức đó khi phù hợp.

Cách dễ nhất để tạo Custom Skill là qua hội thoại với chính Claude. Bạn không cần viết code hay tạo file thủ công — Claude xử lý cấu trúc kỹ thuật cho bạn.

Cách tạo Skill qua hội thoại:

  1. Bắt đầu chat mới và cho Claude biết bạn muốn tạo gì. Ví dụ: "Tôi muốn tạo skill để viết báo cáo kinh doanh hàng quý" hoặc "Tôi cần skill áp dụng brand guidelines của chúng tôi vào bài thuyết trình."
  2. Trả lời các câu hỏi của Claude. Claude sẽ phỏng vấn bạn về quy trình, hỏi những thứ như: Skill này nên làm gì? Đầu ra tốt cho loại công việc này trông như thế nào? Bạn có thể cho ví dụ về khi nào dùng skill này không?
  3. Upload tài liệu tham khảo nếu có. Templates, style guides, tài sản thương hiệu hoặc ví dụ về công việc bạn tự hào đều giúp Claude hiểu chính xác bạn đang tìm kiếm gì.
  4. Lưu skill. Khi xong, Claude tạo file chứa skill có cấu trúc đúng. Lưu nó và skill sẽ sẵn sàng cho Claude sử dụng.

Xem skills của bạn: Tìm tab Customize trong sidebar trái. Ở đó bạn có thể thấy tất cả skills có sẵn và thậm chí chỉnh sửa chúng thủ công hoặc bằng cách chat với Claude.

Custom Skill sẽ xuất hiện trong danh sách Skills bên cạnh Anthropic Skills. Từ đó trở đi, Claude sẽ tự động kích hoạt nó khi bạn làm việc trên các nhiệm vụ liên quan. Bạn có thể cải thiện skills bằng cách lặp lại — yêu cầu Claude chỉnh sửa skill và nó sẽ cập nhật file cho bạn.

Skills vs. Projects

Skills vs. Projects

If both skills and projects can give more context to Claude, when should you use each? Think of it this way: projects store knowledge, skills perform tasks.

Projects are knowledge hubs. They hold the reference materials Claude needs to understand your work — project specs, meeting notes, research documents. When you upload files to a project, Claude draws on that information across every conversation within that project.

Skills are procedural machines. They encode how Claude should execute a task — the specific steps, order of operations, and methodology you want followed every time. Skills shine when you have repeatable workflows you want Claude to run consistently.

The two features complement each other. A skill can reference knowledge stored in a project — your "customer call prep" skill might pull from customer profiles uploaded to a project's knowledge base. The project provides the what (information), the skill provides the how (process).

ProjectsSkills
PurposeStore knowledge Claude referencesDefine processes Claude executes
Best forLong-term context, reference materials, team collaborationRepeatable workflows, multi-step tasks, consistent methodology
ExampleCustomer hub, research buddy, feedback generatorProcess guidelines (brand/legal), blog drafting, PDF creation
PersistenceKnowledge available across all chats in the projectInstructions applied when the skill is invoked

Nếu cả skills và projects đều có thể cung cấp thêm ngữ cảnh cho Claude, khi nào nên dùng cái nào? Hãy nghĩ như thế này: projects lưu trữ kiến thức, skills thực hiện nhiệm vụ.

Projects là hub kiến thức. Chúng chứa tài liệu tham khảo Claude cần để hiểu công việc của bạn — thông số dự án, ghi chú cuộc họp, tài liệu nghiên cứu. Khi bạn upload file vào project, Claude dựa vào thông tin đó trong mọi cuộc hội thoại của project.

Skills là máy thực hiện quy trình. Chúng mã hóa cách Claude nên thực hiện nhiệm vụ — các bước cụ thể, thứ tự thao tác và phương pháp bạn muốn thực hiện mỗi lần. Skills tỏa sáng khi bạn có quy trình lặp lại muốn Claude thực hiện nhất quán.

Hai tính năng bổ trợ cho nhau. Một skill có thể tham chiếu kiến thức lưu trong project — skill "chuẩn bị cuộc gọi khách hàng" của bạn có thể lấy từ hồ sơ khách hàng đã upload vào knowledge base của project. Project cung cấp cái gì (thông tin), skill cung cấp làm thế nào (quy trình).

ProjectsSkills
Mục đíchLưu kiến thức Claude tham chiếuĐịnh nghĩa quy trình Claude thực thi

Ví dụHub khách hàng, trợ lý nghiên cứu, tạo phản hồiHướng dẫn quy trình (thương hiệu/pháp lý), soạn blog, tạo PDF
