Learning objectives

Mục tiêu bài học

By the end of this lesson, you will be able to:

  • Explain what artifacts are and when Claude creates them
  • Share artifacts with colleagues and publish them publicly
  • Troubleshoot common artifact issues

Sau bài học này, bạn sẽ có thể:

  • Giải thích artifacts là gì và khi nào Claude tạo chúng
  • Chia sẻ artifacts với đồng nghiệp và publish công khai
  • Xử lý các vấn đề artifact thường gặp

What are artifacts?

Artifacts là gì?

Artifacts are standalone, interactive outputs that Claude creates in a dedicated window alongside your conversation. Instead of getting a long block of code or text buried in the chat, you see your content rendered and ready to use — whether that's a working website, an interactive chart, or a document you can immediately download.

Claude automatically creates an artifact when content meets certain criteria:

  • It's significant and self-contained, typically over 15 lines
  • It's something you're likely to want to edit, iterate on, or reuse
  • It represents complex content that stands on its own without needing the surrounding conversation
  • It's content you'll want to reference or use later

Artifacts là các đầu ra độc lập, tương tác mà Claude tạo ra trong cửa sổ riêng bên cạnh cuộc hội thoại của bạn. Thay vì nhận một khối code hoặc văn bản dài bị chôn vùi trong chat, bạn thấy nội dung được render sẵn sàng sử dụng — dù đó là website hoạt động được, biểu đồ tương tác hay tài liệu có thể tải xuống ngay.

Claude tự động tạo artifact khi nội dung đáp ứng các tiêu chí nhất định:

  • Đáng kể và độc lập, thường hơn 15 dòng
  • Là thứ bạn có thể muốn chỉnh sửa, lặp lại hoặc tái sử dụng
  • Đại diện cho nội dung phức tạp có thể đứng độc lập mà không cần ngữ cảnh cuộc hội thoại xung quanh
  • Là nội dung bạn muốn tham chiếu hoặc sử dụng sau này

Common artifact types

Các loại artifact phổ biến

Claude can create different types of artifacts, each suited to different needs:

  • Documents (including markdown, plain text, Word docs, PDFs, PowerPoint, and Excel): Great for anything text-heavy that you'll want to export or continue editing — like meeting notes, reports, project plans, blog posts, and other written content.
  • Code snippets: Working code in any programming language — Python, JavaScript, C++, and more. You can view the code, copy it, or download it to use in your own projects.
  • HTML pages: Complete web pages with HTML, CSS, and JavaScript in a single file. Perfect for landing pages, forms, interactive demos, or quick prototypes.
  • SVG images: Scalable vector graphics for logos, icons, illustrations, and other visual elements. These render directly in the artifact window so you can see exactly what you're getting.
  • Mermaid diagrams: Flowcharts, sequence diagrams, Gantt charts, org charts, and more. Describe the relationships you want to visualize, and Claude will create a diagram you can refine.
  • React components: Interactive UI elements with real functionality — calculators, dashboards, games, data visualizations. These aren't just mockups; they include actual logic and respond to user input.

Claude có thể tạo các loại artifact khác nhau, mỗi loại phù hợp với nhu cầu khác nhau:

  • Documents (gồm markdown, plain text, Word docs, PDFs, PowerPoint và Excel): Phù hợp cho mọi thứ nhiều văn bản mà bạn muốn export hoặc tiếp tục chỉnh sửa — như ghi chú cuộc họp, báo cáo, kế hoạch dự án, bài blog và các nội dung viết khác.
  • Code snippets: Code hoạt động được bằng bất kỳ ngôn ngữ lập trình nào — Python, JavaScript, C++ và nhiều hơn nữa. Bạn có thể xem code, copy hoặc tải xuống để dùng trong dự án của mình.
  • HTML pages: Trang web hoàn chỉnh với HTML, CSS và JavaScript trong một file. Hoàn hảo cho landing page, form, demo tương tác hoặc prototype nhanh.
  • SVG images: Đồ họa vector có thể mở rộng cho logo, icon, minh họa và các yếu tố trực quan khác. Chúng render trực tiếp trong cửa sổ artifact để bạn thấy chính xác kết quả.
  • Mermaid diagrams: Flowchart, sequence diagram, Gantt chart, org chart và nhiều hơn nữa. Mô tả các mối quan hệ bạn muốn trực quan hóa, và Claude sẽ tạo diagram bạn có thể tinh chỉnh.
  • React components: Các phần tử UI tương tác với chức năng thực — máy tính, dashboard, game, trực quan hóa dữ liệu. Đây không chỉ là mockup; chúng có logic thực và phản hồi với đầu vào của người dùng.

Creating your first artifact

Tạo artifact đầu tiên

Creating an artifact is as simple as having a conversation. Just describe what you want, and Claude will determine whether to present it as an artifact.

For example, you might say:

  • "Create a flowchart showing our customer onboarding process"
  • "Build an interactive dashboard that lets me input monthly expenses and see a breakdown"
  • "Design a landing page for a productivity app with a hero section and feature list"
  • "Write a project brief template I can reuse for new initiatives"

If Claude doesn't automatically create an artifact when you expect one, you can explicitly ask: "Create this as an artifact" or "Show me this in an artifact."

When Claude generates an artifact, it appears in a dedicated window to the right of your conversation. From here, you can:

  • View different formats: Toggle between a preview (how it looks) and the underlying code
  • Copy content: Click the copy icon to grab the content for use elsewhere
  • Download files: Save the artifact as a file to your computer
  • View code: See exactly what Claude generated under the hood

Tạo artifact đơn giản như một cuộc hội thoại. Chỉ cần mô tả những gì bạn muốn, và Claude sẽ xác định có nên trình bày nó dưới dạng artifact không.

Ví dụ, bạn có thể nói:

  • "Tạo flowchart hiển thị quy trình onboarding khách hàng của chúng tôi"
  • "Xây dựng dashboard tương tác cho phép tôi nhập chi phí hàng tháng và xem phân tích"
  • "Thiết kế landing page cho ứng dụng năng suất với phần hero và danh sách tính năng"
  • "Viết template project brief tôi có thể tái sử dụng cho các sáng kiến mới"

Nếu Claude không tự động tạo artifact khi bạn mong đợi, bạn có thể yêu cầu rõ ràng: "Tạo cái này dưới dạng artifact" hoặc "Cho tôi thấy cái này trong artifact."

Khi Claude tạo artifact, nó xuất hiện trong cửa sổ riêng bên phải cuộc hội thoại. Từ đây, bạn có thể:

  • Xem các định dạng khác nhau: Chuyển đổi giữa preview (giao diện) và code bên dưới
  • Copy nội dung: Click biểu tượng copy để lấy nội dung dùng ở nơi khác
  • Tải xuống file: Lưu artifact dưới dạng file về máy tính
  • Xem code: Xem chính xác những gì Claude đã tạo ra

Sharing and publishing artifacts

Chia sẻ và publish artifacts

Once you've created something useful, you have several options for sharing it.

Copy or download: For personal use or sharing via other channels, use the copy or download buttons in the lower right corner of the artifact window.

Share within your organization (Claude for Work): Team and Enterprise users can share artifacts internally with colleagues. The shared artifact stays within your organization and requires team authentication to access.

Publish publicly: For free, Pro, and Max users, you can publish artifacts to make them accessible to anyone with the link. When you publish:

  • Only the selected version becomes public (your chat remains private)
  • Anyone can view and interact with the artifact without a Claude account
  • Others can "remix" your artifact — opening it in their own Claude conversation to modify and build upon it

To publish, click the "Share" or "Publish" button in the upper right corner of the artifact. You can unpublish at any time. Note: published artifacts are publicly accessible via their link but are not indexed by search engines.

Sau khi tạo được thứ gì đó hữu ích, bạn có một vài tùy chọn để chia sẻ.

Copy hoặc tải xuống: Để sử dụng cá nhân hoặc chia sẻ qua kênh khác, dùng nút copy hoặc download ở góc dưới bên phải cửa sổ artifact.

Chia sẻ trong tổ chức (Claude for Work): Người dùng Team và Enterprise có thể chia sẻ artifact nội bộ với đồng nghiệp. Artifact được chia sẻ ở trong tổ chức và yêu cầu xác thực nhóm để truy cập.

Publish công khai: Với người dùng free, Pro và Max, bạn có thể publish artifact để bất kỳ ai có link đều truy cập được. Khi publish:

  • Chỉ phiên bản được chọn trở thành công khai (chat của bạn vẫn riêng tư)
  • Bất kỳ ai cũng có thể xem và tương tác với artifact mà không cần tài khoản Claude
  • Người khác có thể "remix" artifact của bạn — mở nó trong cuộc hội thoại Claude của họ để sửa đổi và phát triển tiếp

Để publish, click nút "Share" hoặc "Publish" ở góc trên bên phải của artifact. Bạn có thể hủy publish bất cứ lúc nào. Lưu ý: artifact đã publish có thể truy cập công khai qua link nhưng không được lập chỉ mục bởi công cụ tìm kiếm.

Tips for getting the most from artifacts

Mẹo tận dụng tối đa artifacts
  • Be specific about what you want. "Build a budget tracker" is good, but "Build a monthly budget tracker where I can input expenses by category, see a pie chart breakdown, and get a warning when I'm over budget" is better.
  • Describe the end user. Telling Claude who will use the artifact helps it make appropriate design choices. "This flowchart is for new employees" leads to different results than "This flowchart is for the engineering team."
  • Iterate incrementally. Ask Claude to add one feature or make one change at a time. This makes it easier to identify what's working and catch issues early.
  • Request artifacts when needed. If you ask for something substantial and Claude responds in the chat instead of creating an artifact, just say "Please create that as an artifact."
  • Cụ thể về những gì bạn muốn. "Tạo budget tracker" ổn, nhưng "Tạo budget tracker hàng tháng cho phép tôi nhập chi phí theo danh mục, xem phân tích dạng pie chart và nhận cảnh báo khi vượt ngân sách" thì tốt hơn.
  • Mô tả người dùng cuối. Cho Claude biết ai sẽ dùng artifact giúp nó đưa ra lựa chọn thiết kế phù hợp. "Flowchart này dành cho nhân viên mới" dẫn đến kết quả khác với "Flowchart này dành cho nhóm kỹ thuật."
  • Lặp từng bước. Yêu cầu Claude thêm một tính năng hoặc thực hiện một thay đổi mỗi lần. Điều này giúp dễ xác định điều gì hiệu quả và phát hiện vấn đề sớm.
  • Yêu cầu artifact khi cần. Nếu bạn yêu cầu thứ gì đó đáng kể và Claude phản hồi trong chat thay vì tạo artifact, chỉ cần nói "Vui lòng tạo cái đó dưới dạng artifact."

Lesson reflection

Suy ngẫm về bài học

Before moving on, consider:

  • What recurring work could benefit from having an interactive artifact you can reuse?
  • Are there processes in your work that would be clearer as a flowchart or diagram?
  • What prototype or tool would help you test an idea quickly?

Trước khi chuyển sang bài tiếp theo, hãy suy ngẫm:

  • Công việc lặp lại nào có thể được hưởng lợi từ việc có artifact tương tác có thể tái sử dụng?
  • Có quy trình nào trong công việc của bạn sẽ rõ ràng hơn dưới dạng flowchart hoặc diagram không?
  • Prototype hoặc công cụ nào sẽ giúp bạn kiểm tra ý tưởng nhanh chóng?
