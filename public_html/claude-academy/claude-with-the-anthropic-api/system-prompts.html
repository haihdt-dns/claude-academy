System prompts

System prompts

System Prompts Overview

Tổng quan System Prompts

System prompts are a powerful way to customize how Claude responds to user input. Instead of getting generic answers, you can shape Claude's tone, style, and approach to match your specific use case.

System prompt là một cách mạnh mẽ để tùy chỉnh cách Claude phản hồi đầu vào của người dùng. Thay vì nhận câu trả lời chung chung, bạn có thể định hình giọng điệu, phong cách và cách tiếp cận của Claude để phù hợp với trường hợp sử dụng cụ thể của bạn.

Why System Prompts Matter

Tại sao System Prompts quan trọng

Consider building a math tutor chatbot. When a student asks "How do I solve 5x + 2 = 3 for x?", you want Claude to act like a real tutor, not just spit out the answer. A good math tutor should:

  • Initially give hints rather than complete solutions
  • Patiently walk students through problems step by step
  • Show solutions for similar problems as examples

You definitely don't want Claude to:

  • Immediately give direct answers
  • Tell students to just use a calculator

Hãy xem xét việc xây dựng một chatbot gia sư toán. Khi học sinh hỏi "Làm thế nào để giải 5x + 2 = 3 cho x?", bạn muốn Claude hành động như một gia sư thực sự, không chỉ đưa ra câu trả lời. Một gia sư toán giỏi nên:

  • Ban đầu đưa ra gợi ý thay vì giải pháp hoàn chỉnh
  • Kiên nhẫn hướng dẫn học sinh từng bước
  • Đưa ra giải pháp cho các bài toán tương tự làm ví dụ

Bạn chắc chắn không muốn Claude:

  • Đưa ra câu trả lời trực tiếp ngay lập tức
  • Bảo học sinh dùng máy tính

How System Prompts Work

System Prompts hoạt động như thế nào

System prompts provide Claude with guidance on how to respond. You define them as plain strings and pass them into the create function call. The key benefits are:

  • System prompts provide Claude guidance on how to respond
  • Claude will try to respond in the same way someone in the specified role would respond
  • Helps keep Claude on task

Here's the basic structure:

system_prompt = """
You are a patient math tutor.
Do not directly answer a student's questions.
Guide them to a solution step by step.
"""

client.messages.create(
    model=model,
    messages=messages,
    max_tokens=1000,
    system=system_prompt
)

System prompt cung cấp cho Claude hướng dẫn về cách phản hồi. Bạn định nghĩa chúng dưới dạng chuỗi thuần và truyền vào lời gọi hàm create. Các lợi ích chính là:

  • System prompt cung cấp cho Claude hướng dẫn về cách phản hồi
  • Claude sẽ cố gắng phản hồi theo cách mà người trong vai trò được chỉ định sẽ phản hồi
  • Giúp Claude tập trung vào nhiệm vụ

Đây là cấu trúc cơ bản:

system_prompt = """
You are a patient math tutor.
Do not directly answer a student's questions.
Guide them to a solution step by step.
"""

client.messages.create(
    model=model,
    messages=messages,
    max_tokens=1000,
    system=system_prompt
)

Seeing the Difference

Thấy sự khác biệt

Without a system prompt, Claude gives a complete step-by-step solution immediately. This might be helpful, but it doesn't encourage the student to think through the problem themselves.

With the math tutor system prompt, Claude's response changes dramatically. Instead of providing the full solution, Claude asks guiding questions like "What do you think would be a good first step to isolate x? Consider what operation we might need to perform on both sides to start moving terms around."

Không có system prompt, Claude đưa ra giải pháp từng bước đầy đủ ngay lập tức. Điều này có thể hữu ích, nhưng không khuyến khích học sinh tự suy nghĩ về bài toán.

Với system prompt gia sư toán, phản hồi của Claude thay đổi đáng kể. Thay vì cung cấp giải pháp đầy đủ, Claude đặt câu hỏi hướng dẫn như "Bạn nghĩ bước đầu tiên tốt để cô lập x là gì? Hãy xem xét phép tính nào chúng ta có thể cần thực hiện trên cả hai vế để bắt đầu di chuyển các số hạng."

Building a Flexible Chat Function

Xây dựng hàm Chat linh hoạt

Rather than hard-coding system prompts, you can make your chat function more reusable by accepting system prompts as parameters:

def chat(messages, system=None):
    params = {
        "model": model,
        "max_tokens": 1000,
        "messages": messages,
    }
    
    if system:
        params["system"] = system
    
    message = client.messages.create(**params)
    return message.content[0].text

This approach handles an important detail: Claude's API doesn't accept system=None, so you need to conditionally include the system parameter only when it's provided.

Now you can call your chat function with or without a system prompt:

# Without system prompt
answer = chat(messages)

# With system prompt
system = """
You are a patient math tutor.
Do not directly answer a student's questions.
Guide them to a solution step by step.
"""
answer = chat(messages, system=system)

System prompts are essential for creating AI applications that behave consistently and appropriately for their intended purpose.

Thay vì hard-code system prompt, bạn có thể làm cho hàm chat linh hoạt hơn bằng cách nhận system prompt như tham số:

def chat(messages, system=None):
    params = {
        "model": model,
        "max_tokens": 1000,
        "messages": messages,
    }
    
    if system:
        params["system"] = system
    
    message = client.messages.create(**params)
    return message.content[0].text

Cách này xử lý một chi tiết quan trọng: Claude API không chấp nhận system=None, vì vậy bạn cần đưa tham số system vào có điều kiện chỉ khi nó được cung cấp.

Bây giờ bạn có thể gọi hàm chat với hoặc không có system prompt:

# Không có system prompt
answer = chat(messages)

# Có system prompt
system = """
You are a patient math tutor.
Do not directly answer a student's questions.
Guide them to a solution step by step.
"""
answer = chat(messages, system=system)

System prompt rất cần thiết để tạo ra các ứng dụng AI hoạt động nhất quán và phù hợp với mục đích của chúng.

What Is a System Prompt?

A system prompt is a special set of instructions you provide to Claude before the conversation begins. Unlike user messages, it is passed via the system parameter in the API request rather than inside the messages array.

client.messages.create(
    model="claude-opus-4-5",
    max_tokens=1024,
    system="You are a helpful assistant that always responds in formal English.",
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)

The system prompt is processed before any user message, so it shapes every response Claude gives throughout the session.

What to Put in System Prompts

System prompts are ideal for:

  • Role definition — "You are a customer support agent for Acme Corp"
  • Tone and style — "Always respond concisely in plain language. Avoid jargon."
  • Behavioral rules — "Never discuss competitor products. If asked, politely redirect."
  • Context injection — Background knowledge the model needs, such as company policies or product details
  • Output format — "Always respond with a JSON object containing answer and confidence fields"

Think of the system prompt as the job description you give Claude before it starts working for you.

System vs. User Messages

Understanding the difference between the system prompt and user messages is critical:

  • System prompt: Set by the developer. Hidden from the end user. Applied once per session. Used for persistent configuration.
  • User messages: Sent by the end user (or constructed by your app). Visible to Claude as part of the conversation. Change with every turn.

In practice, the system prompt is your opportunity to customize Claude's behavior for your specific use case — before the user ever types a single word.

System Prompt là gì?

System prompt là một tập hợp hướng dẫn đặc biệt bạn cung cấp cho Claude trước khi cuộc hội thoại bắt đầu. Khác với user message, nó được truyền qua tham số system trong API request thay vì bên trong mảng messages.

client.messages.create(
    model="claude-opus-4-5",
    max_tokens=1024,
    system="You are a helpful assistant that always responds in formal English.",
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)

System prompt được xử lý trước bất kỳ user message nào, vì vậy nó định hình mọi phản hồi Claude đưa ra trong suốt phiên làm việc.

Nên đặt gì trong System Prompt

System prompt lý tưởng cho:

  • Định nghĩa vai trò — "You are a customer support agent for Acme Corp"
  • Giọng điệu và phong cách — "Always respond concisely in plain language. Avoid jargon."
  • Quy tắc hành vi — "Never discuss competitor products. If asked, politely redirect."
  • Chèn ngữ cảnh — Kiến thức nền model cần, như chính sách công ty hoặc chi tiết sản phẩm
  • Định dạng output — "Always respond with a JSON object containing answer and confidence fields"

Hãy nghĩ system prompt như bản mô tả công việc bạn đưa cho Claude trước khi nó bắt đầu làm việc cho bạn.

System vs. User Messages

Hiểu sự khác biệt giữa system prompt và user message rất quan trọng:

  • System prompt: Được đặt bởi developer. Ẩn với người dùng cuối. Áp dụng một lần mỗi phiên. Dùng cho cấu hình lâu dài.
  • User messages: Được gửi bởi người dùng cuối (hoặc được xây dựng bởi app của bạn). Hiển thị cho Claude như một phần của cuộc hội thoại. Thay đổi với mỗi lượt.

Trong thực tế, system prompt là cơ hội của bạn để tùy chỉnh hành vi của Claude cho trường hợp sử dụng cụ thể — trước khi người dùng gõ một từ nào.

Key TakeawaysĐiểm chính bài học
  • The system parameter lets you give Claude persistent instructions that apply throughout the entire conversation
  • System prompts set Claude's role, personality, tone, and behavioral constraints before the user says anything
  • Unlike user messages, the system prompt is not visible to the end user — it's your configuration layer
  • Combining a well-crafted system prompt with user messages is the foundation of most real-world Claude applications
  • Tham số system cho phép bạn cung cấp cho Claude các hướng dẫn liên tục áp dụng trong toàn bộ cuộc hội thoại
  • System prompt thiết lập vai trò, tính cách, giọng điệu và các ràng buộc hành vi của Claude trước khi người dùng nói bất cứ điều gì
  • Khác với tin nhắn người dùng, system prompt không hiển thị với người dùng cuối — đây là lớp cấu hình của bạn
  • Kết hợp system prompt được soạn thảo tốt với tin nhắn người dùng là nền tảng của hầu hết các ứng dụng Claude trong thực tế
