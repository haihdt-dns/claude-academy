Deep DiveTìm hiểu thêm

In this exercise, you'll extend your chat application from the previous exercise by adding a system prompt — putting Claude into a specific role before the conversation begins.

What you'll build

An enhanced chat loop that includes a system parameter to:

  • Define Claude's persona (e.g. a customer support agent, a coding tutor, a formal writing assistant)
  • Set behavioral constraints that persist across every turn
  • Combine persistent configuration with dynamic user input

Key concepts applied

  • The system parameter: Passed separately from the messages array — it's processed before any user message
  • Role definition: Use the system prompt to give Claude a job description, tone, and rules
  • Separation of concerns: The system prompt is your configuration layer; user messages are the runtime input

Trong bài tập này, bạn sẽ mở rộng ứng dụng chat từ bài tập trước bằng cách thêm system prompt — đặt Claude vào một vai trò cụ thể trước khi cuộc hội thoại bắt đầu.

Bạn sẽ xây dựng gì

Một vòng lặp chat nâng cao có tham số system để:

  • Định nghĩa nhân cách của Claude (ví dụ: nhân viên hỗ trợ khách hàng, gia sư lập trình, trợ lý viết văn phong trang trọng)
  • Đặt các ràng buộc hành vi duy trì qua mọi lượt hội thoại
  • Kết hợp cấu hình liên tục với đầu vào động từ người dùng

Các khái niệm được áp dụng

  • Tham số system: Được truyền riêng biệt khỏi mảng messages — được xử lý trước bất kỳ tin nhắn người dùng nào
  • Định nghĩa vai trò: Sử dụng system prompt để cung cấp cho Claude mô tả công việc, giọng điệu và quy tắc
  • Phân tách mối quan tâm: System prompt là lớp cấu hình của bạn; tin nhắn người dùng là đầu vào thời gian chạy
Key TakeawaysĐiểm chính bài học
  • Practice adding a system parameter to a Claude API request to control its behavior
  • Combine a crafted system prompt with user messages to build a role-specific assistant
  • Observe how the system prompt shapes every response throughout the session
  • Thực hành thêm tham số system vào API request Claude để kiểm soát hành vi của nó
  • Kết hợp system prompt được soạn thảo với tin nhắn người dùng để xây dựng trợ lý theo vai trò cụ thể
  • Quan sát cách system prompt định hình mọi phản hồi trong suốt phiên làm việc
