Introducing tool useGiới thiệu tool use

Estimated time: 10 minutes (Thời gian ước tính: 10 phút)Estimated time: 10 minutesThời gian ước tính: 10 phút

Tools allow Claude to access information from the outside world, extending its capabilities beyond what it learned during training. By default, Claude only knows information from its training data and can't access current events, real-time data, or external systems. Tool use solves this limitation by creating a structured way for Claude to request and receive fresh information.

Tool cho phép Claude truy cập thông tin từ thế giới bên ngoài, mở rộng khả năng của Claude vượt ra ngoài những gì được học trong quá trình huấn luyện. Theo mặc định, Claude chỉ biết thông tin từ dữ liệu huấn luyện và không thể truy cập các sự kiện hiện tại, dữ liệu thời gian thực hay các hệ thống bên ngoài. Tool use giải quyết hạn chế này bằng cách tạo ra một cách có cấu trúc để Claude yêu cầu và nhận thông tin mới.

The Problem Without Tools

Vấn đề khi không có tool

When users ask Claude for current information, it hits a wall. For example, if someone asks "What's the weather in San Francisco, California?" Claude has to respond with something like "I'm sorry, but I don't have access to up-to-date weather information."

This creates a frustrating user experience when people need real-time data that Claude could theoretically help with if it just had access to current information.

Khi người dùng hỏi Claude về thông tin hiện tại, Claude gặp giới hạn. Ví dụ, nếu ai đó hỏi "Thời tiết ở San Francisco, California hiện tại như thế nào?" Claude phải trả lời kiểu như "Xin lỗi, tôi không có quyền truy cập vào thông tin thời tiết cập nhật."

Điều này tạo ra trải nghiệm người dùng đáng thất vọng khi họ cần dữ liệu thời gian thực mà Claude về mặt lý thuyết có thể giúp được nếu có quyền truy cập vào thông tin hiện tại.

How Tool Use Works

Tool use hoạt động như thế nào

Tool use follows a specific back-and-forth pattern between your application and Claude. Here's the complete flow:

  1. Initial Request: You send Claude a question along with instructions on how to get extra data from external sources
  2. Tool Request: Claude analyzes the question and decides it needs additional information, then asks for specific details about what data it needs
  3. Data Retrieval: Your server runs code to fetch the requested information from external APIs or databases
  4. Final Response: You send the retrieved data back to Claude, which then generates a complete response using both the original question and the fresh data

Tool use theo một quy trình qua lại cụ thể giữa ứng dụng và Claude. Đây là toàn bộ luồng:

  1. Yêu cầu ban đầu: Bạn gửi cho Claude một câu hỏi kèm theo hướng dẫn cách lấy dữ liệu bổ sung từ các nguồn bên ngoài
  2. Yêu cầu tool: Claude phân tích câu hỏi và quyết định cần thêm thông tin, sau đó yêu cầu dữ liệu cụ thể mà nó cần
  3. Truy xuất dữ liệu: Server của bạn chạy code để lấy thông tin yêu cầu từ các API hoặc database bên ngoài
  4. Phản hồi cuối cùng: Bạn gửi dữ liệu đã lấy về lại cho Claude, Claude sau đó tạo ra phản hồi đầy đủ dựa trên cả câu hỏi gốc lẫn dữ liệu mới

Weather Example in Practice

Ví dụ thời tiết thực tế

Let's see how this works with the weather question. The process becomes much more specific:

When a user asks about current weather, you include instructions in your prompt about how to retrieve weather data. Claude recognizes it needs current information and requests weather data for the specific location. Your server then calls a weather API to get real-time conditions and sends that data back to Claude. Finally, Claude combines the fresh weather data with the user's question to provide an accurate, current response.

Hãy xem quy trình này hoạt động như thế nào với câu hỏi về thời tiết. Quy trình trở nên cụ thể hơn nhiều:

Khi người dùng hỏi về thời tiết hiện tại, bạn đưa vào prompt hướng dẫn cách lấy dữ liệu thời tiết. Claude nhận ra nó cần thông tin hiện tại và yêu cầu dữ liệu thời tiết cho địa điểm cụ thể. Server của bạn sau đó gọi API thời tiết để lấy điều kiện thời tiết thời gian thực và gửi dữ liệu đó lại cho Claude. Cuối cùng, Claude kết hợp dữ liệu thời tiết mới với câu hỏi của người dùng để đưa ra phản hồi chính xác, cập nhật.

Key Benefits

Lợi ích chính
  • Real-time Information: Access current data that wasn't available during Claude's training
  • External System Integration: Connect Claude to databases, APIs, and other services
  • Dynamic Responses: Provide answers based on the latest available information
  • Structured Interaction: Claude knows exactly what information it needs and how to ask for it

Tool use transforms Claude from a static knowledge base into a dynamic assistant that can work with live data. This opens up possibilities for building applications that need current information, whether that's weather data, stock prices, database queries, or any other real-time information your users might need.

  • Thông tin thời gian thực: Truy cập dữ liệu hiện tại mà không có trong quá trình huấn luyện của Claude
  • Tích hợp hệ thống bên ngoài: Kết nối Claude với các database, API và dịch vụ khác
  • Phản hồi động: Đưa ra câu trả lời dựa trên thông tin mới nhất có sẵn
  • Tương tác có cấu trúc: Claude biết chính xác thông tin nào cần thiết và cách yêu cầu nó

Tool use biến Claude từ một kho kiến thức tĩnh thành một trợ lý năng động có thể làm việc với dữ liệu trực tiếp. Điều này mở ra khả năng xây dựng các ứng dụng cần thông tin hiện tại, dù đó là dữ liệu thời tiết, giá cổ phiếu, truy vấn database hay bất kỳ thông tin thời gian thực nào người dùng của bạn có thể cần.
