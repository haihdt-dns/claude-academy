Getting an API keyLấy API key

Estimated time: 5 minutes (Thời gian ước tính: 5 phút)Estimated time: 5 minutesThời gian ước tính: 5 phút

In the next video we will be making a request to the Anthropic API. To do so, you will need a secret API key. This guide will walk you through the process of creating an API key.

Trong video tiếp theo, chúng ta sẽ thực hiện một request đến Anthropic API. Để làm vậy, bạn cần một API key bí mật. Hướng dẫn này sẽ dẫn bạn qua từng bước tạo API key.

Step One: Navigate to the Anthropic API Console

Bước 1: Truy cập Anthropic API Console

In your browser, navigate to https://console.anthropic.com/ and log in to your Anthropic account. You'll then see a page like this:

Trong trình duyệt, vào https://console.anthropic.com/ và đăng nhập vào tài khoản Anthropic của bạn. Bạn sẽ thấy trang như sau:

Step Two: Click the 'Get API Keys' button

Bước 2: Nhấn nút 'Get API Keys'

This button can be found towards the top right of the main dashboard page.

Nút này nằm ở phía trên bên phải của trang dashboard chính.

Step Three: Click the 'Create Key' button

Bước 3: Nhấn nút 'Create Key'

At the top right of the page, find the 'Create Key' button and click it.

Ở góc trên bên phải của trang, tìm nút 'Create Key' và nhấn vào.

Step Four: Enter a workspace and name for your key

Bước 4: Nhập workspace và tên cho key

Create the key in workspace 'Default' and enter a name for your key. This name is used to help you identify the keys you generate. Let's use a name of 'Anthropic Course'.

Tạo key trong workspace 'Default' và nhập tên cho key. Tên này giúp bạn nhận dạng các key đã tạo. Hãy dùng tên 'Anthropic Course'.

Step Five: Copy the Key

Bước 5: Sao chép Key

Your API key will then be displayed in a pop up window. Copy this key and hold onto it — we will use it in the next video. This key will only be displayed once, so make sure you copy it!

If you accidentally close the window, delete the old key and generate it again.

API key của bạn sẽ hiển thị trong cửa sổ pop-up. Sao chép key này và giữ lại — chúng ta sẽ dùng nó trong video tiếp theo. Key này chỉ hiển thị một lần, vì vậy hãy đảm bảo bạn đã sao chép!

Nếu bạn vô tình đóng cửa sổ, hãy xóa key cũ và tạo lại.

Your API key grants full access to your Anthropic account and is billed against your account. Treat it like a password:

  • Never commit it to version control (Git). Use environment variables or a secrets manager instead.
  • Store it in a .env file and add .env to your .gitignore.
  • Don't share it in chat messages, screenshots, or public forums.

The standard way to make your key available to the SDK is to set the ANTHROPIC_API_KEY environment variable:

export ANTHROPIC_API_KEY="your-key-here"

The Anthropic Python SDK reads this variable automatically, so you never need to hardcode the key in your code.

API key của bạn cấp quyền truy cập đầy đủ vào tài khoản Anthropic và được tính phí vào tài khoản của bạn. Hãy xử lý nó như mật khẩu:

  • Không bao giờ commit vào version control (Git). Thay vào đó, hãy dùng biến môi trường hoặc secrets manager.
  • Lưu trong file .env và thêm .env vào .gitignore.
  • Không chia sẻ qua tin nhắn chat, ảnh chụp màn hình hay diễn đàn công khai.

Cách chuẩn để cung cấp key cho SDK là đặt biến môi trường ANTHROPIC_API_KEY:

export ANTHROPIC_API_KEY="your-key-here"

Anthropic Python SDK đọc biến này tự động, vì vậy bạn không cần hardcode key trong code.
