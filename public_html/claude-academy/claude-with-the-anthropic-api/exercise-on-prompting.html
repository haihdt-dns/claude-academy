Deep DiveTìm hiểu thêm

In this exercise, you'll take the meal planning prompt from the previous lessons and apply all four prompt engineering techniques one by one, running an evaluation after each step to measure the improvement.

What you'll build

A fully engineered meal plan prompt that incorporates:

  1. Being clear and direct — rewrite the opening line with a direct action verb
  2. Being specific — add output quality guidelines and/or process steps
  3. XML tags — wrap the athlete data in descriptive tags
  4. Providing examples — add one or more ideal input/output pairs

Recommended workflow

  1. Start from your baseline prompt (the naive version)
  2. Apply technique #1, run the eval, record the score
  3. Apply technique #2, run the eval again, record the score
  4. Continue for all four techniques
  5. Compare the scores at each step to see which technique had the biggest impact

Things to watch for

  • Some techniques will have a bigger effect than others — that's normal and task-dependent
  • Occasionally a technique might slightly lower the score — don't panic, it can be a matter of prompt wording
  • The combination of all four is almost always better than any single technique alone

Trong bài tập này, bạn sẽ lấy prompt kế hoạch bữa ăn từ các bài học trước và áp dụng cả bốn kỹ thuật prompt engineering từng cái một, chạy đánh giá sau mỗi bước để đo lường sự cải thiện.

Bạn sẽ xây dựng gì

Một prompt kế hoạch bữa ăn được thiết kế hoàn chỉnh kết hợp:

  1. Rõ ràng và trực tiếp — viết lại dòng mở đầu với động từ hành động trực tiếp
  2. Cụ thể hóa — thêm output quality guidelines và/hoặc process steps
  3. XML tags — bọc dữ liệu vận động viên trong các tag mô tả
  4. Cung cấp ví dụ — thêm một hoặc nhiều cặp input/output lý tưởng

Quy trình làm việc được đề xuất

  1. Bắt đầu từ prompt baseline (phiên bản naive)
  2. Áp dụng kỹ thuật #1, chạy eval, ghi lại điểm
  3. Áp dụng kỹ thuật #2, chạy lại eval, ghi lại điểm
  4. Tiếp tục với cả bốn kỹ thuật
  5. So sánh điểm ở mỗi bước để xem kỹ thuật nào có tác động lớn nhất

Những điều cần chú ý

  • Một số kỹ thuật sẽ có tác động lớn hơn các kỹ thuật khác — điều đó bình thường và phụ thuộc vào nhiệm vụ
  • Đôi khi một kỹ thuật có thể làm giảm điểm một chút — đừng lo lắng, đó có thể là vấn đề về cách diễn đạt prompt
  • Sự kết hợp của cả bốn kỹ thuật hầu như luôn tốt hơn bất kỳ kỹ thuật đơn lẻ nào
Key TakeawaysĐiểm chính bài học
  • Apply all four prompt engineering techniques in sequence on a single prompt
  • Measure the impact of each technique by running evaluations after every change
  • Build intuition for which techniques provide the biggest gains for your use case
  • Áp dụng cả bốn kỹ thuật prompt engineering theo trình tự trên một prompt duy nhất
  • Đo lường tác động của từng kỹ thuật bằng cách chạy đánh giá sau mỗi thay đổi
  • Xây dựng trực giác về kỹ thuật nào mang lại cải thiện lớn nhất cho use case của bạn
