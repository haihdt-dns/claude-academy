Generating test datasetsTạo test dataset

Estimated time: 10 minutes (Thời gian ước tính: 10 phút)Estimated time: 10 minutesThời gian ước tính: 10 phút

Building a custom prompt evaluation workflow starts with creating a solid prompt and then generating test data to see how well it performs. Let's walk through setting up an evaluation system for a prompt that helps users write AWS-specific code.

Xây dựng quy trình đánh giá prompt tùy chỉnh bắt đầu bằng việc tạo một prompt vững chắc, sau đó tạo test data để xem nó hoạt động tốt đến đâu. Hãy cùng xem xét cách thiết lập hệ thống đánh giá cho một prompt giúp người dùng viết code đặc thù cho AWS.

Setting Up the Goal

Thiết lập mục tiêu

Our prompt needs to assist users in writing three specific types of output for AWS use cases:

  • Python code
  • JSON configuration files
  • Regular expressions

The key requirement is that when a user requests help with a task, we return clean output in one of these formats without any extra explanations, headers, or footers.

Here's our starting prompt (version 1):

prompt = f"""
Please provide a solution to the following task:
{task}
"""

Prompt của chúng ta cần hỗ trợ người dùng viết ba loại đầu ra cụ thể cho các trường hợp sử dụng AWS:

  • Code Python
  • File cấu hình JSON
  • Regular expression

Yêu cầu chính là khi người dùng yêu cầu trợ giúp về một tác vụ, chúng ta trả về đầu ra sạch ở một trong các định dạng này mà không có giải thích, header hay footer thêm.

Đây là prompt ban đầu (phiên bản 1):

prompt = f"""
Please provide a solution to the following task:
{task}
"""

Creating an Evaluation Dataset

Tạo Evaluation Dataset

An evaluation dataset contains inputs that we'll feed into our prompt. For each combination of prompt and input, we'll run the prompt and analyze the results.

Our dataset will be an array of JSON objects, where each object contains a "task" property describing what we want Claude to accomplish. We can either create this dataset by hand or generate it automatically using Claude.

Since we're generating test data, this is a perfect opportunity to use a faster model like Haiku instead of the full Claude model.

Evaluation dataset chứa các đầu vào mà chúng ta sẽ đưa vào prompt. Với mỗi tổ hợp prompt và đầu vào, chúng ta sẽ chạy prompt và phân tích kết quả.

Dataset của chúng ta sẽ là mảng các JSON object, trong đó mỗi object chứa thuộc tính "task" mô tả những gì chúng ta muốn Claude thực hiện. Chúng ta có thể tự tạo dataset này hoặc tạo tự động bằng Claude.

Vì chúng ta đang tạo test data, đây là cơ hội hoàn hảo để sử dụng model nhanh hơn như Haiku thay vì model Claude đầy đủ.

Tạo Test Data bằng Code

Let's create a function that automatically generates our test dataset. First, we'll need our helper functions for working with Claude:

def add_assistant_message(messages, text):

def generate_dataset():
    prompt = """
Generate an evaluation dataset for a prompt evaluation. The dataset will be used to evaluate prompts that generate Python, JSON, or Regex specifically for AWS-related tasks. Generate an array of JSON objects, each representing task that requires Python, JSON, or a Regex to complete.

Example output:
```json
[
  {
    "task": "Description of task",
  },
  ...additional
]
```

* Focus on tasks that can be solved by writing a single Python function, a single JSON object, or a single regex
* Focus on tasks that do not require writing much code

Please generate 3 objects.
"""

Testing the Dataset Generation

Kiểm tra việc tạo Dataset

Let's run our function and see what kind of test cases we get:

dataset = generate_dataset()
print(dataset)

This should return three different test cases covering our target outputs — Python functions, JSON configurations, and regular expressions for AWS-specific tasks.

Hãy chạy hàm của chúng ta và xem loại test case nào chúng ta nhận được:

dataset = generate_dataset()
print(dataset)

Điều này sẽ trả về ba test case khác nhau bao gồm các đầu ra mục tiêu — hàm Python, cấu hình JSON và regular expression cho các tác vụ đặc thù AWS.

Saving the Dataset

Lưu Dataset

Once we have our dataset, we'll save it to a file so we can easily load it later during evaluation:

with open('dataset.json', 'w') as f:
    json.dump(dataset, f, indent=2)

This creates a dataset.json file in the same directory as your notebook, containing your list of tasks ready for prompt evaluation.

With this foundation in place, you now have a systematic way to generate test data for evaluating how well your prompts perform across different types of AWS-related coding tasks.

Khi có dataset, chúng ta sẽ lưu nó vào file để có thể dễ dàng tải sau trong quá trình đánh giá:

with open('dataset.json', 'w') as f:
    json.dump(dataset, f, indent=2)

Điều này tạo file dataset.json trong cùng thư mục với notebook của bạn, chứa danh sách các tác vụ sẵn sàng để đánh giá prompt.

Với nền tảng này, bạn giờ có cách có hệ thống để tạo test data để đánh giá mức độ hoạt động của prompt qua các loại tác vụ lập trình liên quan đến AWS khác nhau.

Key TakeawaysĐiểm chính bài học
  • An eval dataset is an array of sample inputs that represent real tasks your prompt will handle in production
  • You can generate test data automatically by prompting Claude — use a faster model like Haiku to keep costs low
  • Use assistant prefilling + stop sequences to get clean JSON output from the dataset generator
  • Save the dataset to a file so it stays consistent across prompt iterations
  • Eval dataset là mảng các đầu vào mẫu đại diện cho các tác vụ thực mà prompt của bạn sẽ xử lý trong production
  • Bạn có thể tự động tạo test data bằng cách prompt Claude — sử dụng model nhanh hơn như Haiku để giảm chi phí
  • Dùng assistant prefilling + stop sequences để nhận JSON sạch từ bộ tạo dataset
  • Lưu dataset vào file để nó nhất quán qua các lần lặp prompt
