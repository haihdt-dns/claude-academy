Chat exercise

Bài tập chat

(~4 minutes)

In this exercise, you'll put into practice everything you've learned about making API requests and multi-turn conversations by building a simple interactive chat application.

What you'll build

A command-line chat loop that:

  • Accepts user input from the terminal
  • Maintains a messages list that grows with each turn
  • Sends the full conversation history to Claude on every request
  • Prints Claude's response and waits for the next user message

Key concepts applied

  • Message history: Append each {role: "user", content: "..."} and {role: "assistant", content: "..."} pair to the list
  • Stateless API: The API has no memory — you must send the entire conversation every time
  • Loop structure: A simple while True loop (Python) or equivalent keeps the chat running until the user exits

Follow along with the video on the original Skilljar course to see a live walkthrough of the implementation.

(~4 phút)

Trong bài tập này, bạn sẽ thực hành những gì đã học về thực hiện API request và hội thoại nhiều lượt bằng cách xây dựng một ứng dụng chat tương tác đơn giản.

Bạn sẽ xây dựng gì

Một vòng lặp chat trên command-line:

  • Nhận đầu vào từ người dùng qua terminal
  • Duy trì danh sách messages phát triển theo từng lượt
  • Gửi toàn bộ lịch sử hội thoại đến Claude mỗi khi request
  • In phản hồi của Claude và chờ tin nhắn tiếp theo từ người dùng

Các khái niệm được áp dụng

  • Lịch sử tin nhắn: Thêm từng cặp {role: "user", content: "..."} và {role: "assistant", content: "..."} vào danh sách
  • API không trạng thái: API không có bộ nhớ — bạn phải gửi toàn bộ cuộc hội thoại mỗi lần
  • Cấu trúc vòng lặp: Một vòng lặp while True đơn giản (Python) hoặc tương đương giữ cho chat tiếp tục chạy cho đến khi người dùng thoát
