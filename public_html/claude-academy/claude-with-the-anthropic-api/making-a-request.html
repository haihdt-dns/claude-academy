Making a requestThực hiện request

Your first request

Request đầu tiên của bạn

With your API key set as an environment variable, you're ready to make your first call. Here's the complete minimal example:

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "What is the capital of France?"}
    ]
)

print(message.content[0].text)

Run this and you should see Claude's response printed to the terminal. Let's break down what each parameter does.

Với API key đã được đặt làm biến môi trường, bạn đã sẵn sàng thực hiện lần gọi đầu tiên. Đây là ví dụ tối giản hoàn chỉnh:

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "What is the capital of France?"}
    ]
)

print(message.content[0].text)

Chạy đoạn code này và bạn sẽ thấy response của Claude được in ra terminal. Hãy phân tích từng tham số.

Request parameters

Các tham số request

model

The model ID to use. We recommend using a pinned version like claude-3-5-sonnet-20241022 for predictable behavior. See the models documentation for the full list.

max_tokens

The maximum number of tokens Claude can generate in its response. This is a hard limit — Claude will stop generating when it reaches this number. A token is roughly 3–4 characters of English text. 1024 tokens is a good default for most short responses.

messages

An array of message objects representing the conversation. Each message has:

  • role — either "user" (your input) or "assistant" (Claude's output)
  • content — the text of the message

For a single-turn request, you only need one message with role: "user". Multi-turn conversations build on this by adding more messages — covered in the next lesson.

model

Model ID để sử dụng. Chúng ta khuyến nghị dùng phiên bản đã ghim như claude-3-5-sonnet-20241022 để có hành vi ổn định. Xem tài liệu về models để biết danh sách đầy đủ.

max_tokens

Số token tối đa Claude có thể tạo trong response. Đây là giới hạn cứng — Claude sẽ dừng tạo khi đạt đến con số này. Một token xấp xỉ 3–4 ký tự tiếng Anh. 1024 token là giá trị mặc định tốt cho hầu hết các response ngắn.

messages

Một mảng các message object đại diện cho cuộc hội thoại. Mỗi message có:

  • role — là "user" (input của bạn) hoặc "assistant" (output của Claude)
  • content — nội dung text của tin nhắn

Với request một lượt, bạn chỉ cần một message với role: "user". Hội thoại nhiều lượt xây dựng dựa trên điều này bằng cách thêm nhiều message hơn — được đề cập trong bài học tiếp theo.

Reading the response

Đọc response

The client.messages.create() call returns a Message object. The key fields:

# The text of Claude's reply
print(message.content[0].text)

# Why did Claude stop generating?
print(message.stop_reason)   # 'end_turn' or 'max_tokens'

# Token usage for cost tracking
print(message.usage.input_tokens)
print(message.usage.output_tokens)

Why content[0]? The content field is a list because Claude can return multiple content blocks (text, tool calls, etc.). For a simple text response, there will be exactly one block at index 0.

If stop_reason is "max_tokens" rather than "end_turn", Claude's response was cut off — increase max_tokens if you need the full reply.

Lệnh client.messages.create() trả về một Message object. Các trường chính:

# Text trong câu trả lời của Claude
print(message.content[0].text)

# Tại sao Claude dừng tạo?
print(message.stop_reason)   # 'end_turn' hoặc 'max_tokens'

# Số token để theo dõi chi phí
print(message.usage.input_tokens)
print(message.usage.output_tokens)

Tại sao lại content[0]? Trường content là một list vì Claude có thể trả về nhiều content block (text, tool call, v.v.). Với response text đơn giản, sẽ có chính xác một block tại index 0.

Nếu stop_reason là "max_tokens" thay vì "end_turn", response của Claude đã bị cắt — hãy tăng max_tokens nếu bạn cần toàn bộ câu trả lời.
