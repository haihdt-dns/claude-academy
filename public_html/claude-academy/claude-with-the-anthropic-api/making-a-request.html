Making a requestThực hiện request

Estimated time: 10 minutes (Thời gian ước tính: 10 phút)Estimated time: 10 minutesThời gian ước tính: 10 phút

Making your first request to the Anthropic API is straightforward once you understand the basic setup and structure. This guide walks through the essential steps to get Claude responding to your prompts using Python.

Thực hiện request đầu tiên đến Anthropic API rất đơn giản khi bạn đã hiểu cấu trúc và thiết lập cơ bản. Hướng dẫn này đi qua các bước thiết yếu để Claude phản hồi các prompt của bạn bằng Python.

Setting Up Your Environment

Thiết lập môi trường

Before making any API calls, you need to install the required packages and configure your API key securely.

First, install the necessary dependencies in your Jupyter notebook:

%pip install anthropic python-dotenv

Next, create a .env file in the same directory as your notebook to store your API key securely:

ANTHROPIC_API_KEY="your-api-key-here"

This approach keeps your API key out of your code and prevents accidentally committing it to version control. Always add .env to your .gitignore file.

Load the environment variables and create your API client:

from dotenv import load_dotenv
load_dotenv()

from anthropic import Anthropic

client = Anthropic()
model = "claude-sonnet-4-0"

Trước khi thực hiện bất kỳ API call nào, bạn cần cài đặt các package cần thiết và cấu hình API key một cách an toàn.

Đầu tiên, cài đặt các dependency trong Jupyter notebook:

%pip install anthropic python-dotenv

Tiếp theo, tạo file .env trong cùng thư mục với notebook để lưu API key an toàn:

ANTHROPIC_API_KEY="your-api-key-here"

Cách này giữ API key khỏi code và ngăn vô tình commit lên version control. Luôn thêm .env vào file .gitignore.

Load biến môi trường và tạo API client:

from dotenv import load_dotenv
load_dotenv()

from anthropic import Anthropic

client = Anthropic()
model = "claude-sonnet-4-0"

The Create Function

Hàm Create

The core of making API requests is the client.messages.create() function. This function requires three key parameters:

  • model — The name of the Claude model you want to use
  • max_tokens — A safety limit on response length (not a target)
  • messages — The conversation history you're sending to Claude

The max_tokens parameter acts as a safety mechanism. If you set it to 1000, Claude will stop generating after 1000 tokens even if it has more to say. Claude doesn't try to reach this limit — it just writes what it thinks is appropriate and stops if it hits the maximum.

Cốt lõi của việc thực hiện API request là hàm client.messages.create(). Hàm này yêu cầu ba tham số chính:

  • model — Tên model Claude bạn muốn sử dụng
  • max_tokens — Giới hạn an toàn về độ dài response (không phải mục tiêu)
  • messages — Lịch sử hội thoại bạn gửi đến Claude

Tham số max_tokens hoạt động như cơ chế an toàn. Nếu bạn đặt là 1000, Claude sẽ dừng tạo sau 1000 token dù có thể nói thêm. Claude không cố gắng đạt đến giới hạn này — nó chỉ viết những gì phù hợp và dừng lại khi đạt tối đa.

Understanding Messages

Hiểu về Messages

Messages represent the conversation between you and Claude, similar to a chat application. There are two types of messages:

  • User messages — Content you want to send to Claude (written by humans)
  • Assistant messages — Responses that Claude has generated

Each message is a dictionary with a role (either "user" or "assistant") and content (the actual text).

Messages đại diện cho cuộc hội thoại giữa bạn và Claude, tương tự ứng dụng chat. Có hai loại message:

  • User messages — Nội dung bạn muốn gửi đến Claude (do người viết)
  • Assistant messages — Các response mà Claude đã tạo ra

Mỗi message là một dictionary với role (là "user" hoặc "assistant") và content (văn bản thực tế).

Making Your First Request

Thực hiện Request đầu tiên

Here's a complete example of making a request to Claude:

message = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=[
        {
            "role": "user",
            "content": "What is quantum computing? Answer in one sentence"
        }
    ]
)

When you run this code, Claude will process your request and return a response object containing the generated text along with metadata about the request.

Đây là ví dụ hoàn chỉnh về thực hiện request đến Claude:

message = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=[
        {
            "role": "user",
            "content": "What is quantum computing? Answer in one sentence"
        }
    ]
)

Khi bạn chạy code này, Claude sẽ xử lý request và trả về response object chứa text đã tạo cùng với metadata về request.

Extracting the Response

Trích xuất Response

The response object contains a lot of information, but you usually just want the generated text. Access it using:

message.content[0].text

This gives you clean, readable output like: "Quantum computing is a type of computation that leverages quantum mechanics principles like superposition and entanglement to process information using quantum bits (qubits), potentially solving certain complex problems exponentially faster than classical computers."

With these basics in place, you can start experimenting with different prompts and building more complex interactions with Claude.

Response object chứa nhiều thông tin, nhưng thường bạn chỉ cần text đã tạo. Truy cập bằng:

message.content[0].text

Điều này cho bạn output rõ ràng, dễ đọc như: "Quantum computing là loại tính toán tận dụng các nguyên lý cơ học lượng tử như superposition và entanglement để xử lý thông tin bằng quantum bit (qubit), có thể giải quyết một số vấn đề phức tạp nhanh hơn theo cấp số mũ so với máy tính cổ điển."

Với những kiến thức cơ bản này, bạn có thể bắt đầu thử nghiệm với các prompt khác nhau và xây dựng các tương tác phức tạp hơn với Claude.

Your first request

With your API key set as an environment variable, you're ready to make your first call. Here's the complete minimal example:

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "What is the capital of France?"}
    ]
)

print(message.content[0].text)

Request parameters

model

The model ID to use. We recommend using a pinned version like claude-3-5-sonnet-20241022 for predictable behavior. See the models documentation for the full list.

max_tokens

The maximum number of tokens Claude can generate in its response. A token is roughly 3–4 characters. 1024 tokens is a good default for most short responses.

messages

An array of message objects. Each has a role ("user" or "assistant") and content (the text). For a single-turn request, you only need one user message.

Reading the response

# The text of Claude's reply
print(message.content[0].text)

# Why did Claude stop generating?
print(message.stop_reason)   # 'end_turn' or 'max_tokens'

# Token usage for cost tracking
print(message.usage.input_tokens)
print(message.usage.output_tokens)

Why content[0]? The content field is a list because Claude can return multiple content blocks (text, tool calls, etc.). For a simple text response there will be exactly one block at index 0.

If stop_reason is "max_tokens" rather than "end_turn", Claude's response was cut off — increase max_tokens if you need the full reply.

Request đầu tiên của bạn

Với API key đã được đặt làm biến môi trường, bạn đã sẵn sàng thực hiện lần gọi đầu tiên. Đây là ví dụ tối giản hoàn chỉnh:

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "What is the capital of France?"}
    ]
)

print(message.content[0].text)

Các tham số request

model

Model ID để sử dụng. Khuyến nghị dùng phiên bản đã ghim như claude-3-5-sonnet-20241022 để có hành vi ổn định. Xem tài liệu về models để biết danh sách đầy đủ.

max_tokens

Số token tối đa Claude có thể tạo. Một token xấp xỉ 3–4 ký tự. 1024 token là giá trị mặc định tốt cho hầu hết các response ngắn.

messages

Mảng các message object. Mỗi cái có role ("user" hoặc "assistant") và content (text). Với request một lượt, bạn chỉ cần một user message.

Đọc response

# Text trong câu trả lời của Claude
print(message.content[0].text)

# Tại sao Claude dừng tạo?
print(message.stop_reason)   # 'end_turn' hoặc 'max_tokens'

# Số token để theo dõi chi phí
print(message.usage.input_tokens)
print(message.usage.output_tokens)

Tại sao lại content[0]? Trường content là một list vì Claude có thể trả về nhiều content block (text, tool call, v.v.). Với response text đơn giản sẽ có chính xác một block tại index 0.

Nếu stop_reason là "max_tokens" thay vì "end_turn", response của Claude đã bị cắt — hãy tăng max_tokens nếu bạn cần toàn bộ câu trả lời.
