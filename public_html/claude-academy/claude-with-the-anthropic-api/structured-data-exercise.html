Deep DiveTìm hiểu thêm

In this exercise, you'll put the structured data techniques from the previous lesson into practice by building a small application that generates clean, raw JSON from Claude.

What you'll build

A function that takes a natural language description and returns a valid AWS EventBridge rule as raw JSON — no markdown fences, no explanatory text.

Key concepts applied

  • Assistant message prefilling: Pre-populate the assistant turn with ```json to steer Claude's output
  • Stop sequences: Pass stop_sequences=["```"] to end generation exactly when the JSON closes
  • Response cleanup: Use json.loads(text.strip()) to parse and validate the result

Extension challenges

  • Try the same technique with Python code snippets — what prefill and stop sequence would you use?
  • Add error handling: if json.loads fails, retry the request with a more explicit prompt
  • Extend to generate multiple EventBridge rules in one call using a JSON array

Trong bài tập này, bạn sẽ áp dụng các kỹ thuật dữ liệu có cấu trúc từ bài học trước bằng cách xây dựng một ứng dụng nhỏ tạo JSON sạch, thô từ Claude.

Bạn sẽ xây dựng gì

Một hàm nhận mô tả ngôn ngữ tự nhiên và trả về AWS EventBridge rule hợp lệ dưới dạng JSON thô — không có markdown fence, không có văn bản giải thích.

Các khái niệm được áp dụng

  • Assistant message prefilling: Điền trước lượt trợ lý với ```json để định hướng đầu ra của Claude
  • Stop sequences: Truyền stop_sequences=["```"] để kết thúc quá trình tạo đúng khi JSON đóng lại
  • Response cleanup: Dùng json.loads(text.strip()) để parse và validate kết quả

Thử thách mở rộng

  • Thử kỹ thuật tương tự với các đoạn code Python — bạn sẽ dùng prefill và stop sequence nào?
  • Thêm xử lý lỗi: nếu json.loads thất bại, thử lại request với prompt rõ ràng hơn
  • Mở rộng để tạo nhiều EventBridge rule trong một lần gọi bằng JSON array
