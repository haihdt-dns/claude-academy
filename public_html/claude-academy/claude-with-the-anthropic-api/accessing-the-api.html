Accessing the API

Truy cập API

The Five-Step Request Flow

Quy trình Request 5 bước

When building applications with Claude, understanding the complete request lifecycle helps you make better architectural decisions and debug issues more effectively. Let's walk through what happens from the moment a user clicks "send" in your chat interface to when Claude's response appears on screen.

Every interaction with Claude follows a predictable pattern with five distinct phases: request to server, request to Anthropic API, model processing, response to server, and response to client.

Khi xây dựng ứng dụng với Claude, hiểu toàn bộ vòng đời request giúp bạn đưa ra quyết định kiến trúc tốt hơn và debug hiệu quả hơn. Hãy cùng xem qua những gì xảy ra từ lúc người dùng nhấn "gửi" trong giao diện chat đến khi response của Claude xuất hiện trên màn hình.

Mỗi tương tác với Claude đều theo một quy trình có thể đoán trước với năm giai đoạn riêng biệt: request đến server, request đến Anthropic API, xử lý model, response đến server và response đến client.

Why You Need a Server

Tại sao cần Server

You should never make requests to the Anthropic API directly from client-side code. Here's why:

  • API requests require a secret API key for authentication
  • Exposing this key in client code creates a serious security vulnerability
  • Anyone could extract the key and make unauthorized requests

Instead, your web or mobile app sends requests to your own server, which then communicates with the Anthropic API using the securely stored key.

Bạn không bao giờ nên thực hiện request đến Anthropic API trực tiếp từ code phía client. Lý do:

  • API request yêu cầu API key bí mật để xác thực
  • Để lộ key này trong code client tạo ra lỗ hổng bảo mật nghiêm trọng
  • Bất kỳ ai cũng có thể trích xuất key và thực hiện request trái phép

Thay vào đó, ứng dụng web hoặc mobile của bạn gửi request đến server của riêng bạn, sau đó server này sẽ giao tiếp với Anthropic API bằng key được lưu trữ an toàn.

Making API Requests

Thực hiện API Request

When your server contacts the Anthropic API, you can use either an official SDK or make plain HTTP requests. Anthropic provides SDKs for Python, TypeScript, JavaScript, Go, and Ruby.

Every request must include these essential fields:

  • API Key — Identifies your request to Anthropic
  • Model — Name of the model to use (like claude-opus-4-5)
  • Messages — List containing the user's input text
  • Max Tokens — Limit for how many tokens Claude can generate

Khi server của bạn liên hệ với Anthropic API, bạn có thể sử dụng SDK chính thức hoặc thực hiện HTTP request thông thường. Anthropic cung cấp SDK cho Python, TypeScript, JavaScript, Go và Ruby.

Mỗi request phải bao gồm các trường thiết yếu sau:

  • API Key — Xác định request của bạn với Anthropic
  • Model — Tên model cần sử dụng (như claude-opus-4-5)
  • Messages — Danh sách chứa văn bản đầu vào của người dùng
  • Max Tokens — Giới hạn số token Claude có thể tạo ra

Inside Claude's Processing

Bên trong quá trình xử lý của Claude

Once Anthropic receives your request, Claude processes it through four main stages: tokenization, embedding, contextualization, and generation.

Tokenization

Claude first breaks your input text into smaller chunks called tokens. These can be whole words, parts of words, spaces, or symbols. For simplicity, think of each word as one token.

Embedding

Each token gets converted into an embedding — a long list of numbers that represents all possible meanings of that word. Think of embeddings as numerical definitions that capture semantic relationships.

Words often have multiple meanings. For example, "quantum" could refer to a discrete unit of physical quantity, quantum mechanics concepts, something extremely small, or quantum computing applications.

Contextualization

Claude refines each embedding based on surrounding words to determine the most likely meaning in context. This process adjusts the numerical representations to highlight the appropriate definition.

Generation

The contextualized embeddings pass through an output layer that calculates probabilities for each possible next word. Claude doesn't always pick the highest probability word — it uses a mix of probability and controlled randomness to create natural, varied responses.

After selecting each word, Claude adds it to the sequence and repeats the entire process for the next word.

Khi Anthropic nhận được request của bạn, Claude xử lý nó qua bốn giai đoạn chính: tokenization, embedding, contextualization và generation.

Tokenization

Claude đầu tiên chia văn bản đầu vào thành các đoạn nhỏ hơn gọi là token. Đây có thể là từ nguyên, một phần từ, khoảng trắng hoặc ký hiệu. Đơn giản hóa thì hãy coi mỗi từ là một token.

Embedding

Mỗi token được chuyển đổi thành embedding — một danh sách dài các số đại diện cho tất cả các nghĩa có thể của từ đó. Hãy nghĩ về embedding như định nghĩa số học nắm bắt các mối quan hệ ngữ nghĩa.

Các từ thường có nhiều nghĩa. Ví dụ, "quantum" có thể đề cập đến một đơn vị rời rạc của đại lượng vật lý, các khái niệm cơ học lượng tử, thứ gì đó cực nhỏ, hoặc các ứng dụng điện toán lượng tử.

Contextualization

Claude tinh chỉnh từng embedding dựa trên các từ xung quanh để xác định nghĩa có khả năng nhất trong ngữ cảnh. Quá trình này điều chỉnh các biểu diễn số để làm nổi bật định nghĩa phù hợp.

Generation

Các embedding đã được ngữ cảnh hóa đi qua một lớp đầu ra tính toán xác suất cho mỗi từ tiếp theo có thể. Claude không phải lúc nào cũng chọn từ có xác suất cao nhất — nó sử dụng kết hợp xác suất và tính ngẫu nhiên có kiểm soát để tạo ra các phản hồi tự nhiên, đa dạng.

Sau khi chọn mỗi từ, Claude thêm nó vào chuỗi và lặp lại toàn bộ quá trình cho từ tiếp theo.

When Claude Stops & The API Response

Khi Claude dừng & API Response

After each token, Claude checks several conditions to decide whether to continue:

  • Max tokens reached — Has it hit the limit you specified?
  • Natural ending — Did it generate an end-of-sequence token?
  • Stop sequence — Did it encounter a predefined stop phrase?

When generation completes, the API sends back a structured response containing:

  • Message — The generated text
  • Usage — Count of input and output tokens
  • Stop Reason — Why generation ended

Your server receives this response and forwards the generated text back to your client application, where it appears in the user interface.

Don't worry about memorizing every detail — the goal is familiarizing yourself with the terminology and overall process you'll encounter when working with Claude's API.

Sau mỗi token, Claude kiểm tra một số điều kiện để quyết định có tiếp tục hay không:

  • Đạt max token — Đã đạt đến giới hạn bạn chỉ định chưa?
  • Kết thúc tự nhiên — Có tạo ra token kết thúc chuỗi không?
  • Stop sequence — Có gặp cụm từ dừng được định nghĩa trước không?

Khi quá trình generation hoàn tất, API gửi lại response có cấu trúc chứa:

  • Message — Văn bản được tạo ra
  • Usage — Số lượng token đầu vào và đầu ra
  • Stop Reason — Lý do generation kết thúc

Server của bạn nhận response này và chuyển tiếp văn bản đã tạo trở lại ứng dụng client, nơi nó xuất hiện trong giao diện người dùng.

Đừng lo lắng về việc ghi nhớ mọi chi tiết — mục tiêu là làm quen với thuật ngữ và quy trình tổng thể bạn sẽ gặp khi làm việc với Claude's API.

How the API works

The Anthropic API is a standard HTTP REST API. You send a POST request to an endpoint with a JSON body describing your message, and you receive a JSON response containing Claude's reply.

Every request includes at minimum:

  • model — which Claude model to use
  • max_tokens — the maximum number of tokens in the response
  • messages — an array of message objects, each with a role ("user" or "assistant") and content

Authentication is handled via an API key passed in the x-api-key HTTP header. We'll set up your API key in the next lesson.

The Python SDK

While you can call the API directly with any HTTP client, Anthropic provides an official Python SDK that handles authentication, request formatting, and error handling for you.

Install it with pip:

pip install anthropic

A minimal example — sending a message and printing the response:

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "Hello, Claude!"}
    ]
)

print(message.content[0].text)

The SDK automatically reads your API key from the ANTHROPIC_API_KEY environment variable. You can also pass it explicitly: anthropic.Anthropic(api_key="your-key").

Understanding the response

The API returns a Message object. Key fields you'll use regularly:

  • message.content — a list of content blocks. For text responses, access the text via message.content[0].text
  • message.model — the model that actually processed the request
  • message.stop_reason — why the model stopped generating: "end_turn" (natural completion) or "max_tokens" (hit the token limit)
  • message.usage — token counts for the request (input_tokens) and response (output_tokens), useful for cost tracking

Throughout this course we'll build on this foundation — adding system prompts, multi-turn conversation history, tools, and more. The basic structure of every call stays the same.

API hoạt động như thế nào

Anthropic API là một HTTP REST API tiêu chuẩn. Bạn gửi một POST request đến một endpoint với body JSON mô tả tin nhắn của bạn, và bạn nhận được JSON response chứa câu trả lời của Claude.

Mỗi request bao gồm tối thiểu:

  • model — model Claude nào sẽ sử dụng
  • max_tokens — số token tối đa trong response
  • messages — một mảng các message object, mỗi cái có role ("user" hoặc "assistant") và content

Xác thực được thực hiện qua API key truyền trong HTTP header x-api-key. Chúng ta sẽ thiết lập API key của bạn trong bài học tiếp theo.

Python SDK

Mặc dù bạn có thể gọi API trực tiếp bằng bất kỳ HTTP client nào, Anthropic cung cấp Python SDK chính thức xử lý xác thực, định dạng request và xử lý lỗi cho bạn.

Cài đặt bằng pip:

pip install anthropic

Một ví dụ tối giản — gửi tin nhắn và in response:

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,

        {"role": "user", "content": "Hello, Claude!"}
    ]

SDK tự động đọc API key của bạn từ biến môi trường ANTHROPIC_API_KEY. Bạn cũng có thể truyền trực tiếp: anthropic.Anthropic(api_key="your-key").

Hiểu cấu trúc response

API trả về một Message object. Các trường chính bạn sẽ dùng thường xuyên:

  • message.content — danh sách các content block. Với text response, truy cập text qua message.content[0].text
  • message.model — model đã thực sự xử lý request
  • message.stop_reason — lý do model dừng tạo text: "end_turn" (hoàn thành tự nhiên) hoặc "max_tokens" (đạt giới hạn token)
  • message.usage — số lượng token cho request (input_tokens) và response (output_tokens), hữu ích để theo dõi chi phí

Trong suốt khóa học này, chúng ta sẽ xây dựng dựa trên nền tảng này — thêm system prompt, lịch sử hội thoại nhiều lượt, tools và nhiều hơn nữa. Cấu trúc cơ bản của mỗi lần gọi vẫn giữ nguyên.
