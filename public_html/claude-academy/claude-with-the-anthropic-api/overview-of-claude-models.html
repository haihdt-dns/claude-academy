Deep DiveTìm hiểu thêm

Anthropic offers several Claude model families, each optimized for different use cases and performance trade-offs. Choosing the right model is one of the first decisions you'll make when building with the API.

Claude 3.7 Sonnet

The most intelligent model in the Claude 3.7 family, with extended thinking capabilities for complex reasoning. Best for tasks that require deep analysis, nuanced writing, and multi-step problem solving where quality is the priority.

Claude 3.5 Haiku

The fastest and most compact model in the Claude 3.5 family. Best for high-volume, latency-sensitive tasks — classification, routing, quick summarization — where speed and cost efficiency matter most.

Claude 3 Opus

Anthropic's most capable model in the Claude 3 family, designed for complex, open-ended tasks. Powerful for nuanced reasoning and long-document analysis, though slower and more expensive than Sonnet.

Model IDs and versioning

When making API calls, you specify the model using its model ID — a string like claude-sonnet-4-5 or claude-3-5-haiku-20241022.

Anthropic provides two ways to reference models:

  • Pinned versions (e.g. claude-3-5-sonnet-20241022) — always call the exact same model snapshot. Recommended for production: predictable behavior, no surprise changes.
  • Latest aliases (e.g. claude-sonnet-4-5) — automatically points to the latest version in that family. Convenient for development, but behavior may change as Anthropic updates the model.

Choosing the right model

A practical framework for model selection:

  • Start with Claude 3.5 Sonnet for most tasks — it strikes the best balance of intelligence, speed, and cost for the majority of use cases.
  • Switch to Haiku when you need high throughput, low latency, or cost is a primary constraint (e.g. real-time chat, large-scale batch jobs).
  • Use Opus or extended thinking when the task genuinely requires maximum reasoning depth — complex code generation, multi-document synthesis, nuanced judgment calls.

Throughout this course, we'll use claude-3-5-sonnet-20241022 as the default model in our examples. As you build your own applications, you can swap in any model ID and your code will work the same way — the API interface is identical across all Claude models.

You can always find the current list of available model IDs in the Anthropic documentation.

Anthropic cung cấp một số dòng model Claude, mỗi dòng được tối ưu hóa cho các trường hợp sử dụng khác nhau và sự đánh đổi về hiệu suất. Chọn đúng model là một trong những quyết định đầu tiên bạn sẽ thực hiện khi xây dựng với API.

Claude 3.7 Sonnet

Model thông minh nhất trong dòng Claude 3.7, với khả năng extended thinking cho lý luận phức tạp. Tốt nhất cho các tác vụ đòi hỏi phân tích sâu, viết lách tinh tế và giải quyết vấn đề nhiều bước khi chất lượng là ưu tiên.

Claude 3.5 Haiku

Model nhanh nhất và nhỏ gọn nhất trong dòng Claude 3.5. Tốt nhất cho các tác vụ có khối lượng lớn, nhạy cảm về độ trễ — phân loại, định tuyến, tóm tắt nhanh — khi tốc độ và hiệu quả chi phí quan trọng nhất.

Claude 3 Opus

Model có khả năng nhất của Anthropic trong dòng Claude 3, được thiết kế cho các tác vụ phức tạp và mở. Mạnh mẽ cho lý luận tinh tế và phân tích tài liệu dài, mặc dù chậm hơn và đắt hơn Sonnet.

Model ID và phiên bản

Khi thực hiện API call, bạn chỉ định model bằng model ID — một chuỗi như claude-sonnet-4-5 hoặc claude-3-5-haiku-20241022.

Anthropic cung cấp hai cách để tham chiếu model:

  • Pinned version (ví dụ: claude-3-5-sonnet-20241022) — luôn gọi chính xác cùng một snapshot model. Được khuyến nghị cho production: hành vi có thể đoán trước, không có thay đổi bất ngờ.
  • Latest alias (ví dụ: claude-sonnet-4-5) — tự động trỏ đến phiên bản mới nhất trong dòng đó. Tiện lợi cho phát triển, nhưng hành vi có thể thay đổi khi Anthropic cập nhật model.

Chọn model phù hợp

Một framework thực tế để lựa chọn model:

  • Bắt đầu với Claude 3.5 Sonnet cho hầu hết các tác vụ — nó đạt được sự cân bằng tốt nhất giữa trí thông minh, tốc độ và chi phí cho phần lớn các trường hợp sử dụng.
  • Chuyển sang Haiku khi bạn cần throughput cao, độ trễ thấp, hoặc chi phí là ràng buộc chính (ví dụ: chat thời gian thực, batch job quy mô lớn).
  • Sử dụng Opus hoặc extended thinking khi tác vụ thực sự đòi hỏi độ sâu lý luận tối đa — tạo code phức tạp, tổng hợp nhiều tài liệu, các quyết định phán xét tinh tế.

Trong khóa học này, chúng ta sẽ sử dụng claude-3-5-sonnet-20241022 làm model mặc định trong các ví dụ. Khi xây dựng ứng dụng của riêng bạn, bạn có thể thay bất kỳ model ID nào và code của bạn sẽ hoạt động theo cùng cách — giao diện API giống hệt nhau trên tất cả các model Claude.

Bạn luôn có thể tìm thấy danh sách các model ID hiện có trong tài liệu Anthropic.
